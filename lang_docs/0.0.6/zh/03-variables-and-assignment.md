# 03 — 变量与赋值

## 3.1 绑定

绑定用 `=` 给名字赋予一个值：

```fleen
x = 42
name = "ada"
```

绑定**默认可变**：之后可以用 `=` 重新赋值。

绑定可以在名字上带类型标注：

```fleen
x: int = 42
name: string = "ada"
empty: [int] = []
```

绑定必须带值；单独的 `x;` 不是绑定。

## 3.2 `const` 绑定

在名字前加 `const` 使绑定不可变：

```fleen
const y = 42
const limit: int = 10
```

给 `const` 重新赋值是编译错误：

```fleen
const y = 42
y = 43        // 错误：不能给不可变变量赋值
```

## 3.3 赋值

当名字在当前作用域已存在且可变时，`=` 是赋值：

```fleen
x = 42
x = 43        // 赋值
x = x + 1     // 用当前值进行赋值
```

- 给 `const` 赋值是编译错误（§3.2）。
- 赋值不能带类型标注——对已存在的 `x` 写 `x: int = 43` 是编译错误；
  类型标注只允许出现在第一次绑定上。

## 3.4 `=` 的含义判定

`=` 只有一种写法。它究竟是新绑定还是赋值，由位置和已存在的绑定决定：

| 位置 | 该名字…… | 含义 |
|------|----------|------|
| 语句位置 | 当前作用域未绑定 | 新绑定 |
| 语句位置 | 当前作用域已绑定 | 赋值 |
| 语句位置，在循环体内 | 函数内此位置之前可见的可变绑定 | **对那个外层变量的赋值**（§3.6） |
| 表达式位置 | 当前作用域已绑定 | 赋值 |
| 表达式位置 | 未绑定 | 编译错误——表达式位置的 `=` 永远不创建绑定 |

```fleen
x = 42        // 绑定
x = 43        // 赋值
```

表达式位置的 `=` 只做赋值（且求值为 `unit`，不是被赋的值）：

```fleen
b = 5
a = b = 3     // a = (b = 3)：b 被赋为 3，a 绑定到 unit
```

```fleen
a = b = 3     // 错误：b 未绑定，而表达式位置从不绑定
```

表达式位置赋值的目标查找**不跨函数边界**：

```fleen
x = 1
func f() {
    y = (x = 2)     // 错误：x 在 f 内不可见
}
```

## 3.5 作用域与遮蔽

每个 `{}` 块都是新作用域。块内创建的绑定在块结束后不可见：

```fleen
if cond {
    x = 42
};
print(x)      // 错误：x 不在作用域内
```

函数体是独立作用域，函数边界不可穿透：函数内的绑定不会与函数外同名
变量发生任何交互。

内层作用域可以重新绑定外层已有的名字（**遮蔽**）。遮蔽必须保持相同的
可变性：

| 外层绑定 | 内层绑定 | 是否允许 |
|----------|----------|----------|
| 可变 | 可变 | 允许 |
| `const` | `const` | 允许 |
| 可变 | `const` | 不允许 |
| `const` | 可变 | 不允许 |

```fleen
x = 42
if cond {
    x = 43         // 新绑定，遮蔽外层 x
};
print(x)           // 42 —— 外层 x 未被修改
```

```fleen
const x = 42
if cond {
    const x = 43   // 合法：const 遮蔽 const
};
```

```fleen
x = 42
if cond {
    const x = 43   // 错误：可变性不匹配
};
```

函数参数可以在其函数体内被遮蔽，且不做可变性检查：

```fleen
func f(x: int): int {
    x = 2          // 合法：遮蔽参数
    x
}
```

用户绑定与内置函数同名（例如 `print`）不算冲突，直接覆盖：此后该名字
指向用户绑定。

## 3.6 循环体内的赋值

`while` 或 `for` 的循环体是**循环作用域**。当 `x = expr` 出现在循环体内
（包括其嵌套块）时：

- 若 `x` 在循环体自身的作用域已绑定 → 赋值。
- 否则，若函数内在该位置之前可见的 `x` 是**可变**绑定 → **对那个外层
  变量赋值**。
- 否则 → 新绑定。

因此计数器惯用法赋值的是外层 `x`：

```fleen
x = 0
while x < 10 {
    x = x + 1      // 对外层 x 赋值
};
print(x as string) // 10
```

外层绑定不可变时，循环内赋值是错误：

```fleen
const x = 0
while x < 10 {
    x = 1          // 错误：不能给 const 赋值
};
```

循环作用域的查找不跨函数边界。函数内部的循环体语句 `x = 1` 在没有局部
`x` 时是**新绑定**，而不是写同名的全局变量：

```fleen
x = 0              // 全局
func f(): int {
    n = 0          // 局部
    while n < 3 {
        x = 5      // 循环体内的新绑定；全局 x 不受影响
        n = n + 1
    };
    x              // 返回局部 x = 5
}
```

循环体内仍然可以遮蔽，但只能发生在循环体的**嵌套块**里：

```fleen
x = 0
while x < 3 {
    x = x + 1
    if true {
        x = 100    // 新绑定，在嵌套块内遮蔽外层 x
    }
};
print(x as string) // 3
```

## 3.7 全局变量

文件顶层的绑定是**全局变量**：在其声明之后对模块内所有函数可见，并且
可以被其他模块导入（第 12 章）。

```fleen
// config.fln
version = 3;

func get_version(): int = version
```

规则：

- 函数可以**读取**全局变量；读取 owned 全局会深拷贝到函数内。
- 函数不能**赋值**给全局变量（§3.6：函数内语句位置的 `=` 永远是局部的）。
  能触达全局的写入只有三种形式：字段写（`g.field = v`）、索引写
  （`g[i] = v`，目标是全局 struct/数组变量），以及跨模块的限定名写
  （`m.g = v`，受 `pub` 约束）。
- `deref g = v`（`g` 是全局 box）会被拒绝；先把 box clone 到局部再写。
- 在 `async func` 体内，全局变量可读但不可写（第 10 章 §10.7）。
