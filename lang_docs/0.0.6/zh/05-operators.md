# 05 — 运算符

运算符优先级从低到高见[附录](15-appendix.md)。

## 5.1 算术运算符

| 运算符 | 意义 | 适用类型 | 示例 |
|--------|------|----------|------|
| `+` | 加法 | `int`, `float`（且两边类型相同） | `1 + 2`, `1.5 + 0.5` |
| `-` | 减法 | `int`, `float` | `10 - 3` |
| `*` | 乘法 | `int`, `float` | `2 * 3` |
| `/` | 除法 | `int`, `float` | `7 / 2`, `7.0 / 2.0` |
| `%` | 取余 | `int` | `7 % 2` |

整数除法和取余按整数语义运算。

## 5.2 比较运算符

| 运算符 | 意义 | 适用类型 |
|--------|------|----------|
| `==` | 相等 | `int`, `float`, `bool`, `string`, `unit` |
| `!=` | 不等 | 同上 |

`enum` 类型不支持 `==` 和 `!=`（0.0.6）。尝试比较枚举值会产生类型错误。

## 5.3 逻辑运算符

| 运算符 | 意义 | 适用类型 |
|--------|------|----------|
| `and` | 逻辑与（短路求值） | `bool` |
| `or` | 逻辑或（短路求值） | `bool` |

```fleen
if x > 0 and y > 0 { "both positive" } else { "no" };
```

## 5.4 一元运算符

| 运算符 | 意义 | 适用类型 |
|--------|------|----------|
| `-` | 一元负号 | `int`, `float` |
| `!` | 逻辑非 | `bool` |

```fleen
x = -42;
ok = !false;
```

## 5.5 类型转换 `as`

`as` 用于类型转换。0.0.2 仅支持**标量到 `string`** 的转换；完整转换将随泛型（0.1.0）到来。

```fleen
print(42 as string);
print(true as string);
```

枚举类型不能转换为 `string`（0.0.6）。

## 5.8 后缀运算符

| 运算符 | 意义 | 示例 |
|--------|------|------|
| `()` | 函数调用 | `f(x, y)` |
| `[]` | 数组索引（有边界检查） | `arr[0]` |
| `.` | 字段访问（struct 字段）或成员访问（模块） | `p.x`, `std.io.println` |
| `?` | `Result` 传播 | `div(a, 2)?` |
| `await` | 驱动 `Future<T>` | `task() await` |

这些运算符绑定最紧，按左到右链式使用。
