# 02 — 语句与分号

## 2.1 语句

语句是以下之一：

- 变量绑定或赋值：`x = 42;`（第 03 章）
- 语句位置的 `if`、`while`、`for` 或 `choose`（第 06 章）
- 用作语句的表达式，例如函数调用：`print("hi");`
- 声明：`func`、`struct`、`import`、`pub`、`const`（各见相应章节）

## 2.2 分号

分号是**可选的**：语句可以用显式 `;` 结束，也可以直接以换行结束。下面
两个程序等价：

```fleen
x = 1;
y = 2;
```

```fleen
x = 1
y = 2
```

两类声明在任何情况下都不写分号：

- `func` 声明：

  ```fleen
  func add(a: int, b: int): int = a + b     // 函数体之后不写分号
  ```

- 函数体的最后一个表达式（即返回值）：

  ```fleen
  func f(): int {
      x = 1;
      x + 1        // 不写分号：这是返回值
  }
  ```

  在这里写 `x + 1;` 会丢弃该值，函数将不返回值。

在 `choose` 表达式中，各 `when` 子句和 `otherwise` 子句不写分号；只有当
整个 `choose` 单独作为语句使用时才写分号（第 06 章 §6.4）。

## 2.3 语句边界

语句边界在换行处判定。**两条语句不能写在同一行**：

```fleen
x = 1 y = 2     // 语法错误
```

换行并不总是结束语句——某些记号会把表达式延续到下一行：

| 换行后的记号 | 效果 | 示例 |
|--------------|------|------|
| 二元运算符（`+ - * / % == != < > <= >= and or`） | 延续表达式 | `x = 1` ⏎ `+ 2` → `x = 1 + 2` |
| 一元 `-` | 延续表达式 | `x = 1` ⏎ `- 2` → `x = 1 - 2` |
| `(` | 延续表达式（调用） | `f()` ⏎ `(g())` → `f()(g())` |
| `[` | 延续表达式（索引） | `f()` ⏎ `[0]` → `f()[0]` |
| `.` `?` | 延续表达式 | |
| `else` `elif` `when` `otherwise` | 挂接到前面的构造 | `if c { 1 }` ⏎ `else { 2 }` |
| 标识符、字面量、`func`、`const`、`if`、`while`、`choose`、`import`、`box`、`deref`、`move`、`clone`、`!`、`{` | 结束当前语句，开始新语句 | `x = 1` ⏎ `y = 2` → 两条语句 |

各种行为的示例：

```fleen
// 跨行延续
x = 1 +
    2;

f()
(g());        // f()(g()) —— 调用链；想在 f() 后断开请写 `;`

if x > 0 {
    a = 1
}
else {
    a = 2
}
```

```fleen
// 两条独立语句
x = 1
!flag
```

```fleen
// 已结束的 if 不能再接 else
if x > 0 {
    a = 1
};
else {
    a = 2
}             // 语法错误：else 出现在已结束的 if 之后
```

## 2.4 块表达式作为语句

行首的 `{` **不会**结束上一条语句（这是为了让 Allman 风格的大括号保持
可用）。因此，块表达式用作语句时需要在前面加分号：

```fleen
x = 1
{ print(x) }      // 语法错误：`{` 延续了上面的语句
```

```fleen
x = 1
;{ print(x) }     // 合法：前导分号
```

只含绑定的块可以单独出现在语句位置：

```fleen
{
    x = 1
}
```

## 2.5 值丢弃规则

- 表达式语句会丢弃它的值（`Result` 值除外——`Result` 不允许被静默丢弃，
  见第 09 章 §9.4）。
- 控制流表达式（`if`、`while`、`choose`）用作语句时只为副作用求值；其
  尾部分号是可选的：

  ```fleen
  if x > 0 { print("pos"); };     // 显式分号，合法
  if x > 0 { print("pos"); }      // 同一条语句，分号省略
  while x < 3 { x = x + 1 };     // 同样的规则
  ```
